# Forex Alpha - Multi-Agent Currency Prediction System

## Overview
Machine learning system for predicting major currency pairs (EUR/USD, GBP/USD, USD/JPY) using ensemble models and a multi-agent architecture.

## Project Structure
- **Data Acquisition**: MT5, FRED, News sentiment data pipelines
- **Data Understanding**: EDA, statistical analysis, visualization
- **Feature Engineering**: Technical indicators, macro features, sentiment scores
- **Modeling**: Random Forest, XGBoost, LightGBM, Neural Network ensemble
- **Agents**: Technical, Fundamental, Sentiment, and Ensemble agents
- **Deployment**: Streamlit web app, Docker support
