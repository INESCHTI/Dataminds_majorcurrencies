PROJECT VISION:
Build a multi-agent FX trading platform that generates explainable, high-confidence 
trading signals by integrating macroeconomic, technical, sentiment, and event-driven 
market insights.

BUSINESS OBJECTIVES (BOs):

BO1: Improve FX Decision Quality Through Multi-Dimensional Market Understanding
   - Integrate macroeconomic, technical, sentiment, and event-driven insights
   - Provide analysts with unified, explainable market view
   - Support 4 major currency pairs (EURUSD, USDJPY, GBPUSD, USDCHF)

BO2: Generate Explainable and Actionable Alpha Signals
   - Transform multi-agent insights into clear buy/sell recommendations
   - Include confidence levels and detailed reasoning
   - Enable cross-agent confirmation ("Four-Eyes Principle")

BO3: Reduce Risks Related to False Signals
   - Implement signal validation and conflict resolution
   - Improve recommendation robustness
   - Limit decisions based on partial or noisy information

BO4: Ensure System Reliability and Operational Robustness
   - Monitor data quality and pipeline integrity
   - Track model performance and latency continuously
   - Guarantee stable, reliable system operation

BO5: Enable Transparent Evaluation and Decision Support
   - Develop automated daily/weekly/monthly reporting
   - Create real-time dashboard for analysts
   - Maintain complete audit trail of decisions

4.1 AGENT ARCHITECTURE OVERVIEW
────────────────────────────────────────────────────────────────────────────

Three Agents will be built:

AGENT 1: Sentiment Analysis Agent (EASIEST - Start Here!)
├── Input: News articles from PostgreSQL
├── Processing: NLP sentiment analysis
├── Output: BULLISH/NEUTRAL/BEARISH signal + confidence
└── Time: 3-4 days to build

AGENT 2: Macroeconomic Analysis Agent (MEDIUM)
├── Input: FRED economic indicators from PostgreSQL
├── Processing: Economic analysis + ML model
├── Output: BULLISH/NEUTRAL/BEARISH signal + confidence
└── Time: 1-2 weeks to build

AGENT 3: Technical Multi-Timeframe Analysis Agent (HARDEST)
├── Input: Price features from InfluxDB (1H, 4H, 1D)
├── Processing: Trained ML model + cross-timeframe logic
├── Output: BUY/SELL/NEUTRAL signal + confidence
└── Time: 2-3 weeks to build

────────────────────────────────────────────────────────────────────────────

4.2 SIGNAL GENERATION
────────────────────────────────────────────────────────────────────────────

Component 1: Alpha Signal Engine
- Aggregates all 3 agent signals
- Weighted combination (Macro 40%, Technical 40%, Sentiment 20%)
- Generates final trading signal with confidence score

Component 2: Signal Validator (4-Eyes Principle)
- Validates agent agreement (minimum 2/3 agents must agree)
- Implements conflict resolution rules
- Outputs validated signal for execution
